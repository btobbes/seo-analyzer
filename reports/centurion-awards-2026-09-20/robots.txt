# Note on current behaviour: these rules are not the only thing in play. A

# describe only what we permit. Whether any given assistant
# can actually fetch these pages today is decided upstream of this file.
# Each section states "Allow: /" explicitly so no parser (or SEO tool)
# mistakes the app/API disallows for a content block.
